# KAISER Portfolio

[简体中文](README_zh.md)

A responsive personal portfolio built with Astro and TypeScript. The site presents an engineering background, selected software projects, and a public contact channel through reusable components and structured content.

## Implementation

- Component-based pages for introduction, experience, projects, and contact.
- Structured profile and project data under `src/data/`.
- Static production output generated by Astro.
- Local Caddy serving and Cloudflare Tunnel configuration examples.
- Public-content checks, type checking, and Vitest tests.

## Development

Use Node.js and npm:

```bash
npm ci
npm run dev
```

Build and preview:

```bash
npm run check
npm run build
npm run preview
```

## Local serving on Windows

The production serving scripts require PowerShell and Caddy:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/start-site.ps1
powershell -ExecutionPolicy Bypass -File scripts/verify-site.ps1
```

The local origin is <http://127.0.0.1:8080/>. Stop it with `scripts/stop-site.ps1`.

## Verification

```powershell
npm run audit:public
npm run check
npm run build
npm test -- --run
```
